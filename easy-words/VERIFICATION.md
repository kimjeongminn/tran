# 검증 결과

2026-09-30 로컬 환경에서 확인했습니다.

- 프로덕션 빌드와 TypeScript 검사 통과.
- 결과 스키마 검증, 불확실한 결과의 행동·숫자 제거, 잘못된 JSON 거부, 주의 문구 읽기: 단위 테스트 4개 통과.
- 실제 브라우저에서 390px 모바일 / 1280px 데스크톱 화면 확인. 가로 넘침 없음.
- 설정 열기·큰 글씨 적용, 직접 글 입력, 원문 펼치기·수정, 빈 정보 카드 숨기기 확인.
- API 키 미설정 오류가 안내 문구로 표시되는 것 확인.
- 테스트 응답을 사용한 정상 결과·불확실성 결과 전환 확인. 브라우저 예외 없음.
- 실제 로컬 API에 짧은 입력(400), 다른 출처(403), 과도한 본문(413)을 보내 차단 확인.
- RTDB 초기 JSON은 전체 41바이트, `/public/app` 값은 22바이트(UTF-8, 공백 제외).

실제 OpenAI 키·Firebase 프로젝트 연결, 휴대폰 실제 마이크/한국어 TTS, GitHub 업로드, Vercel 배포는 이 환경에서 완료하지 않았습니다. 결과 화면 검증에는 테스트용 응답을 사용했으며 실제 AI 품질 검증을 의미하지 않습니다. 실제 사용자와의 사용성·접근성 평가는 별도로 필요합니다.
